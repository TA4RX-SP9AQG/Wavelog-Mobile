Android companion app for Wavelog, the self-hosted amateur radio
(ham radio) logging software. Requires a self-hosted Wavelog server
(v3.2.0 or later) and an API v2 token.

Features:

* QSO logging with callsign lookup, band/mode/RST, DXCC info, grid
  square and signal map
* QSL confirmation status (LoTW, eQSL, QRZ.com)
* Contest mode with serial/exchange fields and session management
* DX cluster spots with band/mode filtering
* Logbook browsing, search, edit and delete
* Statistics: DXCC progress, band/mode breakdowns, streak tracking
* Station profile management
* POTA / SOTA / WWFF reference fields
* ADIF import and export
* Achievements and antenna compass

This F-Droid build does not include the Community/chat feature from
the Play Store version, since that depends on Firebase and Google
Play Services.

Third-party services:

Besides your own Wavelog server, the app contacts these fixed,
hard-coded services for specific features:

* www.contestcalendar.com - upcoming contest list (home screen, widget)
* jo30.de, falling back to www.dxwatch.com - DX cluster spots
* www.hamqsl.com - solar/propagation data
* api.pota.app and api2.sota.org.uk - POTA/SOTA spot lookup and posting
* spots.wwff.co - WWFF spot lookup
* tile.openstreetmap.org - map tiles

Callsign lookup goes through your own Wavelog server. QRZ.com is only
opened as a browser link and is never contacted directly by the app.
